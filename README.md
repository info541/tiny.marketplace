# the tiny marketplace

A fun discovery marketplace for small cosmetic & wellness brands — browse products, search ingredients, read reviews, and talk shop.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s in this mockup

- Home discovery experience with featured brands & products
- Browse by category (sunscreen, deodorant, protein, skincare, hair, oral)
- Ingredient search (contains / free-from)
- Brand & product detail pages with reviews
- Community talk threads

Sample data lives in `src/lib/data.ts`. Shopify sync, auth, and checkout are next.
